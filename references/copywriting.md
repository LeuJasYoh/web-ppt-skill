# 幻灯片文案写作纪律（去 AI 味）

> 来源：经 629 篇文章、282.7 万字对照检验的去 AI 味研究（lieflat-less-ai-tone）的**屏显适配版**，加一条信息守恒元规则。
> 用途：写标题 / kicker / lead / 要点 / 金句时的生成侧硬约束——**写每一句时直接遵守**，不是写完再清洗。checklist「内容」区块的自检依据。

## 屏显文案的特殊性

幻灯片是短语和短句，不是长文：kicker、大标题、卡片描述各只有一句。AI 味在长文里毁掉一段，在幻灯片上毁掉的是版面最显眼的位置——所以下面的规则按"生成时约束"执行。

## 生成硬规则（命中即改写）

1. **禁翻案腔**：「不是 X 而是 Y」「看似 X 实则 Y」「你以为 X 其实 Y」→ 拆掉框架，直接给判断。标题尤其高频——PPT 标题就该是判断句本身。
2. **禁空转句引列表**：列表前那行必须有信息量。"我见过的几种典型场景："只负责宣布"下面有列表" = 违规；改成给出结论或数据的那一行。
3. **禁提示语冒号**：「一句话总结：」「核心是：」「原因如下：」→ 删掉提示语，让内容自己站出来。
4. **禁起手式**：「说白了」「说穿了」「先说结论」。
5. **禁拟人化喻体**：「像一位智慧的导师」「像你的私人秘书」→ 写它**实际做了什么**。物象/品牌类比可以（"像 IKEA 的说明书"），人格化职业角色不行。
6. **翻译腔 5 种**（标题重灾区）：①15 字以上的前置定语连环（"的"×3）②「当…时」开头 ③「对于…来说」话题壳 ④句首「然而，」⑤「这意味着」复述前句——标题里五种全都要拆。
7. **禁相邻句同款骨架**：连续叙述句的逗号数、成分顺序、长度雷同时，改写其中一句的句法。同页并列卡片之间的刻意排比**不算**——那是版式节奏。
8. **顿号分句内 ≤2 个**：一项里顿号串三项以上，改写其中一项的句法，或把罗列交给版式（卡片/表格/图标行）承载。
9. **禁序数词顶格小标题**：「一、二、三、四」连续顶格 → 用内容命名小标题。
10. **概括表述不得盖掉已有数据**：素材里有具体数字，正文却写「显著提升」「大幅下降」 = 违规。数字上屏，形容词退场。

## 负面清单（不要过度规避）

- **问句/设问保留**——人类使用频率是 AI 的 17 倍，问句当标题有效且像人。
- **比喻保留**（人类 2.4 倍）——只禁第 5 条的拟人化职业喻体。
- **不为了"像人"**强行拆短句、堆单字虚词、反复写全称——这些方向本身就是错的。

## 信息守恒（元规则）

- 用户给的数字、事实、限定词**不许放大、模糊、删除**：「可能提升 12%」改成「提升 12%」是篡改语气强度。
- 不新增用户没给的数据、因果、引语；页面上每个论断都要能指回素材来源。
- 最小改动：改要改的那一句，不顺手润色全篇。

## 生成后自检（30 秒）

```bash
grep -rn "不是.*而是\|这意味着\|对于.*来说\|一句话总结\|说白了\|先说结论\|像一位" src/slides/*.vue
```

有命中 → 按对应规则改写；零命中不代表合格，对照第 7/8/10 条再扫一眼连续叙述句与罗列。
